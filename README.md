# 🌤️ Previsão do Tempo + IA

Projeto web que combina dados de clima em tempo real com inteligência artificial para sugerir roupas e atividades com base na temperatura, umidade e condições meteorológicas da cidade pesquisada.


## 📋 Sobre o Projeto

O objetivo é facilitar o dia a dia das pessoas, oferecendo não só informações sobre o clima, mas também recomendações personalizadas usando IA. Além disso, conta com *reconhecimento de voz* para buscar cidades de forma prática!

### ✨ Funcionalidades
- Busca de previsão do tempo por nome de cidade (escrita ou voz)
- Exibição de dados como temperatura, umidade, velocidade do vento e condições climáticas
- Sugestões de roupas e atividades baseadas nas informações do clima (via IA)
- Interface responsiva para usar em celular ou computador


## 🛠️ Tecnologias Utilizadas
- *Front-end*: HTML, CSS, JavaScript
- *APIs*: 
  - [OpenWeatherMap](https://openweathermap.org/) (dados meteorológicos)
  - [Web Speech API (webkitSpeechRecognition)](https://developer.mozilla.org/pt-BR/docs/Web/API/Web_Speech_API)


## 🚀 Como Rodar o Projeto

### Pré-requisitos
- Navegador compatível com Web Speech API (Chrome, Edge)
- Chave de API do OpenWeatherMap (gratuita - disponível no site oficial)
